## 📖 À propos

**UnfriendlySMP** est un serveur Minecraft **Survival MultiPlayer** français où seuls les plus forts survivent. 

Pas de pay-to-win, pas de raccourcis. Juste toi, tes compétences et la nature sauvage. Forme des alliances, construis ton empire ou détruis celui des autres — la politique du serveur est entre tes mains.

### 🎯 Notre vision

- ⚔️ **Survie pure** — Aucun avantage payant
- 🏰 **Bases & Factions** — Construis, allie-toi, domine
- 🛡️ **Anti-Cheat** — Un environnement loyal et compétitif
- 🎉 **Événements hebdomadaires** — Tournois, chasses au trésor, boss raids
- 💬 **Communauté active** — Un Discord vivant et accueillant

## 🚀 Rejoindre le serveur

### Prérequis

- **Minecraft Java Edition** version **1.21.2**
- Un compte Microsoft (obligatoire depuis 2021)
- Une connexion Internet stable

### Étapes d'installation

1. **Télécharge** le launcher officiel sur [minecraft.net](https://www.minecraft.net/)
2. **Lance** Minecraft et sélectionne la version **1.21.2**
3. Clique sur **Multijoueur** → **Ajouter un serveur**
4. Colle l'IP : `Unfriendly-smp.mcgo.io`
5. **Rejoins** et commence ton aventure. Bonne chance 🔥
